# To-Do App

A simple and lightweight To-Do List application built using HTML, CSS, and JavaScript. This project allows users to add tasks to a list to keep track of their daily activities.

## Features

- **Add Tasks**: Users can input text and add items to the list.
- **Dynamic List**: Tasks are displayed instantly upon adding.
- **Simple UI**: A clean interface with a dark theme.

## Technologies Used

- **HTML5**: For the structure of the web page.
- **CSS**: For styling the application (linked via `style.css`).
- **JavaScript**: For handling the logic of adding tasks (linked via `script.js`).

## How to Run

1. Clone this repository or download the source code.
2. Navigate to the project folder.
3. Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, etc.).

## Project Structure

- `index.html`: The main entry point containing the HTML structure.
- `style.css`: Contains the styles for the application.
- `script.js`: Contains the functionality to handle user input and list management.
